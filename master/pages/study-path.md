# Study path and preparation for the Abitur {#study-path}

## Entry and lower secondary {#S1}

Start with M1 if modelling, program logic or file organisation are unfamiliar. Then work through M2 and M3 in order. Check whether you can describe an input with its unit, trace a loop and write your own test cases. M4 and M5 apply the same approach to networks and databases. The data analysis in M9-L1 is accessible after M2.

## Upper secondary and optional routes {#S2}

For the basic path, take the lessons labelled basic level in M5–M10. Use the prerequisites below each lesson heading. The advanced path adds formal computability, complexity classes, additional modelling approaches, concurrency and more demanding transfer exercises. When preparing for an exam, first check your state and school's topic list and assessment format. School years, course options and Abitur profiles vary.

## Check your progress {#S3}

Work through a worked example first, then cover the solutions and complete the self-check. Compare your reasoning as well as your answers. If you struggle with a prerequisite, revisit the linked lesson. For the project, record at least one normal case, one boundary case and one error case with expected and observed results.
